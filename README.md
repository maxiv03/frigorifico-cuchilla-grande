# Frigorífico Cuchilla Grande

Sitio de demostración de un frigorífico uruguayo **ficticio**, exportador de carne vacuna y ovina.
Proyecto de portfolio de [fourvexa.com](https://fourvexa.com). Marca, personas y cifras son inventadas.

Next.js 16 · TypeScript · Tailwind CSS 4 · next-intl (ES/EN) · Supabase · Vercel.
